# 煎好日｜訂單串接 Google Sheet 部署說明

網站結帳 →（POST）→ Google Apps Script 網頁應用程式 → 寫入 Google 試算表，並可寄 Email 通知店家。

## 一、建立試算表與程式（約 5 分鐘）

1. 到 Google 雲端硬碟新增一份試算表，命名例如「煎好日訂單」。
2. 試算表選單 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的 `Code.gs` 內容全部刪掉，貼上本資料夾的 [`Code.gs`](Code.gs)，按儲存。
4. 上方函式選單選 `setup` → **執行**。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→ 允許。
   執行完成後，試算表會出現三個工作表：
   - **訂單**：每筆訂單一列，「狀態」欄有下拉選單（新訂單／製作中／可取餐／已完成／已取消），會自動上色。
   - **訂單明細**：每個品項一列，方便做銷售統計。
   - **商品**：價目表。**結帳金額以這裡的價格為準**；取消勾選「上架」即可暫停販售該品項。
5. （選用）函式選單選 `testOrder` → 執行，「訂單」工作表會多一筆測試訂單，確認無誤後可刪除。

## 二、部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**。
2. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 按「部署」，複製 **網頁應用程式網址**（結尾是 `/exec`）。

## 三、把網址填到網站

打開 `index.html`，找到這一行：

```js
const ORDER_API='';
```

把網址貼進引號內，例如：

```js
const ORDER_API='https://script.google.com/macros/s/AKfycb.../exec';
```

儲存並發布後，網站就會從「模擬結帳」自動切換成真實下單，購物車、結帳視窗、隱私權說明的文字也會一起改成正式版本。

> 也可以直接把網址告訴 Claude，由 Claude 幫你填入並合併到 main。

## 四、新訂單 Email 通知（選用）

Apps Script 左側 **專案設定（齒輪）→ 指令碼屬性 → 新增屬性**：

| 屬性 | 值 |
| --- | --- |
| `NOTIFY_EMAIL` | 要收到通知的信箱（多個用逗號分隔） |

## 日後修改

- **改價格、上下架**：直接改「商品」工作表，不用重新部署。
- **新增商品**：網站 `index.html` 的 `products` 與「商品」工作表都要加上同一個商品編號。
- **改了 `Code.gs`**：要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。
- **運費**：修改 `Code.gs` 開頭的 `SHIPPING_FEE`。

## 已內建的保護

- 金額由伺服器依「商品」工作表重新計算，網頁上的價格被竄改也無效。
- 每次結帳有唯一請求編號，網路重送或連點不會重複建單。
- 同一支電話 30 秒內只能下一單；隱藏的防機器人欄位被填寫時不寫入。
- 顧客輸入開頭為 `= + - @` 的內容會被跳脫，避免被試算表當成公式執行。
- 訂單編號格式：`JGD-年月日-流水號`，例如 `JGD-20261116-0001`。
